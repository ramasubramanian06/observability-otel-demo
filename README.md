# 🔭 Microservices Observability on EKS — OpenTelemetry Demo (Jaeger, Prometheus, Grafana)


This project deploys the **OpenTelemetry Astronomy Shop Demo** — a real-world, polyglot microservices application — onto **Amazon EKS** using its official **Helm chart**, with the primary goal of hands-on learning around **observability**: distributed tracing with **Jaeger**, metrics collection with **Prometheus**, and dashboarding with **Grafana**.

Unlike a typical "deploy and forget" demo, this repo focuses specifically on **how observability data flows through a microservices system** — how traces, metrics, and logs are generated by the app, collected by the OpenTelemetry Collector, and visualized across the three tools above.

---

## 📌 Project Goals

- Deploy a realistic, multi-service  e-commerce application on Kubernetes (EKS).
- Understand how the **OpenTelemetry Collector** receives and routes telemetry data.
- Set up and explore **distributed tracing** using Jaeger.
- Set up and explore **metrics monitoring** using Prometheus + Grafana.
- Build practical, interview-ready knowledge of observability concepts on Kubernetes — not just theory.

## 🔍 Observability Deep Dive

This project's main focus was **not** the shop application itself, but understanding the three pillars of observability it ships with out of the box:

### 🧵 Jaeger — Distributed Tracing
- Every request across the microservices (e.g., a checkout flow spanning cart → payment → shipping → email) is instrumented and exported as spans to Jaeger via the OpenTelemetry Collector.
- Used Jaeger's UI (`:16686`) to trace individual requests end-to-end, inspect service latency, and identify slow spans across the call chain.

### 📊 Prometheus — Metrics Collection
- Prometheus scrapes metrics exposed by the OpenTelemetry Collector and cluster components.
- Explored basic PromQL queries to inspect request rates, error rates, and resource metrics per service.

### 📈 Grafana — Visualization
- Grafana was connected to Prometheus as a data source to visualize service and cluster health on pre-built and custom dashboards.
- Used dashboards to correlate metric spikes with traces seen in Jaeger.
